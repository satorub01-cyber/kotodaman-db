# キャラクター登録基準ガイド（イベント・コラボ・紐付けストーリー・ひらがな・雛形）

本書は、コトダマンDBにおいてキャラクターの **イベント・コラボ（`event`）の基準**、**周年と紐付けストーリーの対応表**、**キャラ名（ひらがな / `name_ruby`）の表記ルール**、および **雛形作成時のタイトル規約** をまとめたAI・運用者向けの基準ガイドです。

> [!TIP]
> 本ガイドは MCP Resource **`kotodaman://guide/character-entry`** としても配信されています。下書き作成の全体手順・フィールド入力規則は [character-draft-guide.md](character-draft-guide.md)（`kotodaman://guide/character-draft`）を合わせて参照してください。

---

## 1. イベント・コラボの基準について

`event`（および関連イベント項目）を整理・判定する際は、以下の基本原則を厳守してください。

> [!IMPORTANT]
> **イベント・コラボ設定の基本注意事項**
> * ⚠️ **明確なストーリーがない場合は省略可能**だが、**なるべく紐付きそうなストーリーを見つけること**。
> * ⚠️ **季節イベントや周年などに実装されている場合はそれも記載すること**。
> * ⚠️ **季節イベントや周年などで実装されたストーリーに紐付いている場合**、該当の季節イベントや周年などを記載すること（下記「[2. 紐付けストーリーについて](#2-紐付けストーリーについて)」の対応表を参照）。
> * ⚠️ **季節イベントの階層はなるべく絞ること**。
> * ⚠️ **参考にするニュース記事に、「初登場」と書かれているか確認すること**。

> [!NOTE]
> MCP ツール経由でキャラクター下書きを作成する場合、`event` / `sub_event` / `guerilla_root` は画像単体から推測して勝手に付与せず、原則としてユーザー指定や根拠となる公式情報（ニュース記事等）の確認に基づいて指定してください（既存ターム確認は `get_terms(taxonomy: "event", search: "キーワード")` を使用）。

### ① ガチャキャラ
**形式**: `大枠のストーリー名 + 章の名前 + 該当ガチャ`（季節イベント・周年がある場合は先頭に含める）

* **例：カレン(佑く)**
  * おたすけ天使の昇格試験!?
  * 狂える屋敷からの招待状
  * 満天言霊祭
* **例：イアツ(学校)**
  * ちびっ子学園日誌
  * ダマコレ
* **例：ウラミ(勇言)**
  * お正月2021
  * お正月2021召喚
  * 勇言隊集結！
* **例：ちかげ(恋の旋律)**
  * コトダマンの夏2026"DIJ"
  * レジェンドシフトフェス召喚
* **例：グランドンヘループ**
  * 8周年記念
  * おたすけ天使の昇格試験!?
  * おたすけ天使の面目躍如
  * グランドフェス召喚

### ② 降臨キャラ
**形式**: `大枠のストーリー名 + 章の名前 + 降臨名`（季節イベント・周年・コラボ作品名がある場合は含める）

* **例：カノン**
  * "ことば"の歩むさき
  * "世界樹"にもよおす疑問
  * カノン【魔級】【破滅級】
* **例：アタシデツネ(佑く)**
  * ことだまみれ2026
  * おたすけ天使の昇格試験!?
  * 新春をつつむ瑞兆
  * アタシデツネ(佑く)【超級】
* **例：ソフィスト**
  * 8周年記念
  * おたすけ天使の昇格試験!?
  * ぜーんぶまとめて大団円!!
  * ソフィスト【破滅級】
* **例：恐竜グリード**
  * 仮面ライダー
  * 仮面ライダー×コトダマンコラボ第3弾
  * 恐竜グリード【破滅級】

### ③ 大討伐・超決戦・強襲キャラ
**形式**: `大枠のストーリー名 + 章の名前 + （特定の名前があれば） + 大討伐 or 超決戦 or 強襲`

* **例：グンバツ(佑く)**
  * 7.5周年記念イベント「ワードリームパーク」
  * おたすけ天使の昇格試験!?
  * 謎のバランシング案件到来
  * 理窟言ふ間に一熱波【大討伐】
  * 大討伐
* **例：ダシュリ(水着)**
  * コトダマンの夏2026
  * ムオンと想い出
  * 大討伐
* **例：狛治&恋雪**
  * 鬼滅の刃
  * 「コトダマン」×アニメ「鬼滅の刃」コラボ第3弾
  * 猗窩座再来【超決戦】
  * 超決戦
* **例：刹那**
  * モンスト
  * 「モンスト」×「コトダマン」コラボ第3弾
  * 秘ノ獄 絶光の刹那【破滅級】
  * 強襲

### ④ 配布キャラ
**形式**: `大枠のストーリー名 + 章の名前`
（※プレゼントボックスに配布される場合は `+ 配布`）

* **例：おとぎ**
  * "ことば"の歩むさき
  * 世界樹にもよおす疑問
* **例：ちかげ(月夢)**
  * 7.5周年記念イベント「ワードリームパーク」
  * 月を仰ぎて契る夢
  * かなう夢、さめる夢
* **例：オカルン(萎えるぜ)**
  * ダンダダン
  * 『コトダマン』× TVアニメ『ダンダダン』コラボ 第1弾
  * 配布

### ⑤ モードシフト後実装キャラ
**形式**: `大枠のストーリー名 + 章の名前 + 素体の入手方法 + 降臨名など`

* **例：プッツンガロス(闇)**
  * 裏・言冥界クエスト
  * プッツンガロス【魔級】
  * 魔神再臨 憤怒【魔級】
* **例：釘崎野薔薇(渋谷事変)**
  * 呪術廻戦
  * 『コトダマン』×TVアニメ『呪術廻戦』渋谷事変コラボ
  * 呪術廻戦召喚
* **例：石川五右衛門(獣神化・改)**
  * モンスト
  * 「モンスト」×「コトダマン」コラボ第6弾
  * モンストコラボ召喚第4弾
  * 石川五右衛門(獣神化・改)【超級】
* **例：お父様(神の力)**
  * 鋼の錬金術師
  * 鋼の錬金術師 FULLMETAL ALCHEMIST 復刻コラボ
  * お父様【魔級】【破滅級】
  * 超決戦イベント「神を呑みこみし者」
  * 超決戦

### ⑥ コラボパックキャラ
**形式**: `コラボの作品名 + コラボの弾 + コラボ記念パック`

* **例：仮面ライダーカイザ**
  * 仮面ライダー
  * 仮面ライダー×コトダマンコラボ第5弾
  * コラボ記念パック

## 3. キャラ名（ひらがな / `name_ruby`）について

キャラクター名のひらがな読み（`name_ruby`）を入力する際は、以下のルールに従ってください（カッコ `()` / `（）` 内の文字列は含めません）。

1. **① `&` が含まれるキャラクターは、全角の `＆` を入力する**
2. **② 伸ばし棒が含まれるキャラクターは、伸ばし棒（`ー`）を入力する**
3. **③ 「`ヴ`」はカタカナで入力する**

* **入力例**:
  * `アルセーヌ&ソロモン` → **`あるせーぬ＆そろもん`**
  * `ヴェルドラ` → **`ヴぇるどら`**

## 4. 雛形作成について

* **タイトルに「`雛形`」の2文字を含めること**。
* （補足）タイトルに「雛形」または「雛型」を含む投稿はテンプレート記事として自動保護され、MCP経由のキャラクター検索・変更・削除対象から除外されます。
